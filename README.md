## 合规口径（必须遵守）

依据商业计划书 **第十六章 合规与法务红线** 与 **第十三章 叙事分级**：

### 医疗红线
- ✅ 可用：养护、辅助、机制、研究、参考
- ❌ 禁用：疗效、治疗、抗衰、防病、逆龄、根治、失眠治愈
- 顶部合规声明固定呈现：「产品为养护设备，不替代医疗诊断与治疗」
- 精力净值分附近必须标注「非医疗 / 健康诊断评分」

### 叙事三级
- **消费者口径**：本项目主轴，使用 lib/content.ts 中的 cta/product/sections 内容
- **投资人口径**：仅在 `/investors` 路由下，措辞含「目标值」「路线图」「里程碑驱动」
- **监管口径**：不做医疗宣称、不做多级返利

### 数据隐私
- 不爬取隐私、不做假人设骚扰触达
- 仅公开内容获客

## 动效语言

- **慢节奏**：1.2–2s 过渡，禁止炫技
- **波形微动**：14–24s 循环，呼应"系统在持续工作"
- **数字滚动**：进入视口时启动 cubic ease-out
- **入场动效**：渐显 + 轻微上浮，不用 slide
- **节点呼吸**：3s 周期，opacity 0.4 → 1

所有动效均为 `whileInView` 触发，避免首屏过载。
